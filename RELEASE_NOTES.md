**English** · Download **`ChestCounter.exe`** below and run it. Nothing to install.

> **Turn on replays in Fortnite first**: *Settings → Game → Replays → Record Replays: On*. The tool only reads these replay files: no game modification, no access to the game's memory.

**What's new in 1.0.5**
- Brand-new design: dark midnight background, dark glass cards and a single warm gold accent instead of the parchment look
- Clean modern headings and figures, tabs as one segmented bar, gold buttons and switches, softer shadows and rounded corners
- The report (your chances, chests per day, matches, treasures) uses the same look, with clearer colors for odds and Treasure Hours
- The in-game overlay is unchanged

This version is based on [LED-N/Fortnite-ChestCounter](https://github.com/LED-N/Fortnite-ChestCounter) (MIT). Updates are checked on this repository.
